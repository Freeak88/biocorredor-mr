# Seguridad y privacidad

No publiques vulnerabilidades, credenciales, tokens, datos personales,
coordenadas sensibles ni bases de producción en issues o pull requests.

Para reportar una vulnerabilidad, contactá de forma privada a las personas
mantenedoras del repositorio. Incluí:

- versión o commit afectado;
- pasos para reproducirla;
- impacto estimado;
- evidencia mínima necesaria;
- una forma segura de contactarte.

Las coordenadas de especies sensibles, propiedades privadas y participantes
deben tratarse como información restringida. La aplicación permite separar
visibilidad pública y de equipo, pero la configuración de producción debe ser
revisada antes de publicar datos reales.
