# Consentimiento de participantes

Texto a mostrar y registrar antes de participar:

> Autorizo el tratamiento de mis datos de identificacion, contacto y participacion exclusivamente para la organizacion, validacion y documentacion del proyecto. Comprendo que mi nombre podra asociarse internamente a las observaciones realizadas y que las ubicaciones sensibles o datos personales no seran publicados sin autorizacion.

El consentimiento debe ser libre, informado, especifico y registrado con version del texto, fecha/hora, usuario y dispositivo. La negativa no debe impedir retirar la participacion futura ni solicitar aclaraciones sobre el uso de los datos.
