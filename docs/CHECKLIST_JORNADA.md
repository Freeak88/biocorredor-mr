# Checklist de jornada

## Antes de salir

- [ ] Sectores delimitados y accesos restringidos identificados.
- [ ] Equipos codificados (`EQ-01`, `EQ-02`, ...).
- [ ] Protocolo `INV-GENERAL v1.0` publicado.
- [ ] Participantes y dispositivos registrados.
- [ ] Mapa de sectores disponible sin conexion.
- [ ] Cinco observaciones de prueba creadas y sincronizadas.
- [ ] Hora sincronizada en todos los telefonos.
- [ ] Punto de encuentro y horario de cierre confirmados.
- [ ] Coordenadas publicas y reservadas separadas.

## Durante el recorrido

- [ ] Evento iniciado con equipo, sector, integrantes, protocolo, clima, ambiente y objetivo.
- [ ] Cada observacion tiene hora, GPS/precision, organismo, sustrato, cantidad y observador.
- [ ] Fotos originales completas y diagnosticas tomadas.
- [ ] Registros dudosos marcados para revision.
- [ ] Incidentes y sectores no recorridos anotados.

## Cierre

- [ ] Hora de cierre, distancia y tiempo efectivo registrados.
- [ ] Todos los telefonos sincronizados.
- [ ] Eventos sin cierre revisados.
- [ ] Duplicados y coordenadas anomalas revisados.
- [ ] Hashes y manifiesto generados.
- [ ] Originales bloqueados.
- [ ] CSV, GeoJSON y copia de respaldo descargados.
- [ ] Acta completada y firmada.
