ENM-BGEN vs FungiMap

Comparativa capa por capa — Análisis para integración de modelado de nicho ecológico
Aletheia · Abril 2026 ENM-BGEN: BGEN/UNAJ · MIT License · Autor: D.N. Sánchez Leguizamón

🍄 FungiMap (nuestro)

  • Mapa colaborativo de hongos silvestres
  • React + Vite + Leaflet + PocketBase
  • 1,110 registros (GBIF + MO + usuarios)
  • Clima 14 días, luna, fotoperiodo, altitud
  • Geofirma, IA (Gemini), PWA, chat
  • Stack: TypeScript, Docker, nginx

🌿 ENM-BGEN (referencia)

  • Modelado de nicho ecológico, 19 plantas nativas
  • R + biomod2 + Leaflet
  • GBIF + iNaturalist (estático, batch)
  • WorldClim + SRTM (variables macro)
  • Ensemble: GLM+GBM+RF+MAXNET+XGBOOST
  • AUC 0.93–0.98, TSS 0.70–0.91

📝 Notas / Decisiones pendientes

Stack para SDM: ¿Python puro (scikit-learn + rasterio + folium) o wrapper R → Python? Python se integra directo con el stack existente.

Especies iniciales: ¿Arrancar con las top 10 por registros (Coprinus comatus, Schizophyllum commune, Amanita muscaria, etc.) o todas las que superen 30 registros?

MapBiomas: Descargar de plataforma.argentina.mapbiomas.org. ¿Usar solo 2024 o serie temporal?

Horizonte MycoData: Los rasters + registros validados + contexto climático = dataset de entrenamiento. ¿Exportar en qué formato? GeoJSON + CSV + GeoTIFF.

API de predicción: ¿Endpoint REST (FastAPI) o proceso batch semanal? Para empezar, batch semanal es suficiente.
