# Código de conducta

Biocorredor MR busca ser un proyecto abierto, respetuoso y útil para barrios,
organizaciones, escuelas, universidades y equipos comunitarios.

Esperamos que todas las personas:

- traten a las demás con respeto;
- reciban preguntas y críticas de buena fe;
- documenten sus decisiones con claridad;
- protejan la privacidad de participantes y comunidades;
- eviten afirmaciones ambientales, taxonómicas o jurídicas que no puedan
  sostenerse con evidencia.

No se toleran acoso, discriminación, amenazas, publicación de datos privados,
hostigamiento ni sabotaje deliberado del proyecto.

Para reportar un problema de conducta, abrí un issue privado o contactá a las
personas mantenedoras indicadas en el repositorio. Los reportes se tratarán con
la mayor confidencialidad posible.
